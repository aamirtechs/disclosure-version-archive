Runs 100% in your browser. Your files never leave this device.

Data is stored only in page memory plus the JSON export you download. There is no server. Refreshing the page clears the in-memory archive, so export before you leave.

How it works

  • Add each disclosure version with its effective dates, then close the previous version so ranges do not overlap.
  • The manifest hash makes an archived version tamper-evident: re-import the JSON and the hash should match.
  • Use lookup by date when a question arrives about an older lead: you get the wording that was in effect then, not todays page.
  • Sample wording in this demo is neutral text written for the demo. It is sample wording, not real legal text.
